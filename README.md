# Next.js 14 App - GraphQL 'CMS' Project

## Features

### User Base Roles

#### Admin: Full Access

- ➡️ **Add Post Blogs** ➡️ **Update Post Blogs** ➡️ **Delete Post Blogs**
- ➡️ **Add Video Blogs** ➡️ **Update Video Blogs** ➡️ **Delete Video Blogs**
- ➡️ **Add User** ➡️ **Change User Roles**
- ➡️ **Profile Update**

#### Editor: Only Edit the Data

- ➡️ **Add Post Blogs** ➡️ **Update Post Blogs** ➡️ **Only Delete Own Post Blogs**
- ➡️ **Add Video Blogs** ➡️ **Update Video Blogs** ➡️ **Only Delete Own Video Blogs**
- ➡️ **Profile Update**

#### Other Users: Access to Own Data

- ➡️ **Add Own Post Blogs** ➡️ **Update Own Post Blogs** ➡️ **Delete Own Post Blogs**
- ➡️ **Add Own Video Blogs** ➡️ **Update Own Video Blogs** ➡️ **Delete Own Video Blogs**
- ➡️ **Profile Update**
